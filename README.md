# PowerCo Customer Churn Analysis

## Project Overview
This project analyzes customer churn for PowerCo, an energy utility serving small and medium-sized businesses. The objective is to explore customer behavior, investigate potential price sensitivity, engineer relevant features, and build a machine learning model to predict customer churn.

**Project Type:** BCG X Data Science Virtual Job Simulation — Forage  
**Domain:** Energy & Utilities  
**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

## Business Problem
Customer churn can affect revenue and long-term business growth. The project investigates customer characteristics, consumption patterns, pricing variables, and churn indicators to identify potentially useful signals for understanding and predicting churn.

## Project Workflow

### 1. Exploratory Data Analysis (EDA)
- Examined dataset structure, data types, and descriptive statistics.
- Checked missing values and duplicate records.
- Explored customer characteristics, consumption patterns, pricing variables, and churn distribution.
- Used visualizations to investigate patterns in the data.

### 2. Feature Engineering
- Prepared features for machine learning.
- Investigated price-related variables and potential price sensitivity.
- Developed features to support churn prediction.

### 3. Machine Learning & Evaluation
- Built a Random Forest classification model.
- Evaluated model performance using appropriate classification metrics.
- Considered class imbalance and the business implications of model errors.

## Repository Structure

- `BCG_X_PowerCo_Polished_EDA.ipynb` — Exploratory data analysis
- `BCG_X_PowerCo_Feature_Engineering.ipynb` — Feature engineering
- `BCG_X_PowerCo_Modeling_Evaluation.ipynb` — Model training and evaluation

## Key Learning Outcomes
- Exploratory data analysis and data quality checks
- Feature engineering for customer churn prediction
- Classification modeling with Random Forest
- Model evaluation and business-oriented interpretation
- Translating analytical findings into potential business recommendations
